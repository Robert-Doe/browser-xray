03Commonly Confused Pairs

The wrong statementThe correction
"CORS blocks the cross-origin request from being sent." Neither CORS nor SOP ever stops a request from being SENT — only whether the RESPONSE is exposed to script. This exact gap is what makes CSRF (Module 32) possible even on a perfectly CORS/SOP-compliant site.
"SameSite and Same-Origin mean the same thing, just for cookies." Same-SITE (used by SameSite) compares only the registrable domain — a.example.com and b.example.com ARE same-site. Same-ORIGIN (used by SOP) requires an EXACT match on scheme, host, AND port — those same two URLs are NOT same-origin.
"CSP is a cross-origin policy, like SOP or CORS." CSP has nothing to do with cross-origin READING — it governs whether a script EXECUTES at all, same-origin or not. A page's own, legitimately same-origin inline script can be blocked by CSP just as easily as a cross-origin one.
"HTTPS and HSTS are the same protection." HTTPS/TLS (Module 15) encrypts and authenticates a connection ONCE established. HSTS (Module 31) ensures that connection gets established as HTTPS in the first place, rather than being silently downgraded before TLS ever runs — genuinely different failure modes, both real, neither substituting for the other.

04Scenario-Matching Quiz

"A hidden form on evil.com auto-submits a POST to your bank, and your session cookie rides along."
SameSite (or its absence) — this is CSRF, governed by whether the cookie attaches, not by SOP or CORS.
"An injected `<script>` tag from a stored XSS bug is present in the page's HTML but never runs."
CSP — blocking execution of content already on the page, regardless of its origin.
"A public weather API explicitly allows any website's JavaScript to read its JSON responses."
CORS — the deliberate, server-declared relaxation of SOP's default.
"Typing `http://` for a banking site you've visited before results in your browser silently connecting via `https://` instead, with no visible redirect."
HSTS — the pre-flight, client-side rewrite, remembered from a prior visit.
"A script from a different origin's `fetch()` call gets a response back but throws when the code tries to read its body."
SOP (or CORS's absence) — the request succeeded; only reading the response was blocked.
