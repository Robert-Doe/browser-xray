SOP (Same-Origin Policy)

SOP is the default rule that mail delivered to your mailbox is only ever opened by YOU — not a rule about whether mail gets delivered at all, only about who's allowed to open the envelope once it arrives.

SOP is the browser's DEFAULT, always-on rule: script running on one origin cannot read the response of a request to a different origin. Module 17 proved the precise mechanism directly — the network request still happens; SOP only withholds the RESPONSE from the calling script afterward.

SOP needs no server configuration at all — it's the baseline every other policy on this page either relaxes (CORS) or supplements (everything else).

Most commonly confused with CORS — see the connections hub for the exact wrong statement this produces.
