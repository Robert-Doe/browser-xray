How PID, Handle, Token, and SID Connect

Four terms, constantly conflated in casual conversation about Windows security — here's exactly how they relate.

01Side by Side

02The Chain, Visually

A PID alone gets you nowhere. Your own TOKEN — built from SIDs — is what the kernel actually checks before handing back a HANDLE.

03Commonly Confused Pairs

The wrong statementThe correction
"I have the PID, so I can just read that process's memory." A PID grants nothing. You need a HANDLE, obtained via OpenProcess(), which the kernel only grants after checking YOUR token against the target's protections — exactly what Module 4's inspect_child_process.py demonstrated needing to do explicitly.
"Administrator privilege and high integrity level are the same thing." They're separate axes. Integrity level (a SID on your token) governs what can write to you. Group membership (a DIFFERENT SID, also on your token) governs what privileged operations you can request. A process can be Medium integrity and still hold Administrator group membership at the same time — this is literally how UAC's split-token behavior works.
"A token IS a SID." A token CARRIES many SIDs (your user identity, every group, your integrity level) — it's a bundle, not a single identifier. Asking "what's the SID of that token" is like asking "what's the sentence of that book" — a token has several distinct SIDs serving different purposes.
"Two processes with the same PID number could be the same process." PIDs are reused over time as processes exit and new ones start — the SAME number can validly refer to two completely unrelated processes at different points in time. A PID alone, without also knowing WHEN, doesn't uniquely identify a process across time the way you might assume.

04Scenario-Matching Quiz

You're handed each scenario below. Which term does it actually describe?

"The number 4821, printed in Task Manager's 'PID' column."
PID — a bare, public, reusable-over-time process identifier.
"The specific integer 0x38 that only means something inside MY process, referring to a file I opened with read-only access."
Handle — opaque outside the holding process, and carrying the exact rights it was granted with.
"The complete bundle describing that I'm user 'bob', a member of 'Administrators', currently running at Medium integrity."
Token — the full credential set an access check is compared against.
"Just the specific string S-1-16-8192, on its own, meaning 'Medium integrity.'"
SID — one atomic identifier, in this case for an integrity level specifically.
